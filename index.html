    02 / PAYMENT RAILS

    五种路径，
    五种账单。

    不用记住每张卡。先认出它走哪条路径，汇率和费用就大致有数了。下面每类给几张代表卡。

    01 FX

    银行购汇
    多币种直付

    外币消费 → 外币账户 → 银行现汇卖出价

    交易币种能直接进入卡内外币账户，不经过卡组织二次折算。路径最短，代价是银行牌价本身的买卖点差。

    工行 奋斗万事达 币种不在账户列表内时，会先折美元。
    02 MULTI

    银行购汇
    纯外币多币种

    外币消费 → 外币账户 → 中行人民币卡购汇转入

    没有人民币账户，但支持多个外币币种。消费直接进入对应外币账户；还款时先用另一张中行人民币卡购汇，再转入外币账户。

    中行 莫奈世界卡 没有人民币账户，需另一张中行卡购汇。
    03 CNY

    卡组织汇率
    人民币入账

    外币消费 → 卡组织折人民币 → 人民币账单

    人民币账户直接收单，只经过一次卡组织折算，没有银行购汇环节。路径干净，最终汇率由入账日决定。

    中行万事网联 / 招行万事达人民币卡 一次折算，通常没有货币转换费。
    04 V

    美元中转
    Visa 双币与全币种

    外币消费 → Visa 折美元 → 银行美元卖出价

    典型美元账户卡：卡组织先折美元，银行再购汇。招行全币种通常 0 货转；交行双币卡叠加 1.5% 货转后，通常明显更贵。

    招行 全币种 Visa / 交行 Visa 双币卡 美元消费时，才会少一次转换。
    05 UP

    银联通道 · 人民币入账

    外币消费 → 银联折人民币 → 人民币账单

    双标卡走银联网络时，由银联直接折算人民币入账，没有银行购汇环节，通常也没有货币转换费。能否走银联，取决于收单网络；少数套卡若按外币账户入账后再转人民币，成本会更接近“多币种直付”。

    工行 银联双标 / 交行 银联环球卡 和卡组织人民币卡往往只差几个基点。

    代表卡只用于说明支付路径，不构成办卡或产品推荐。卡组织、币种账户、货转费、返现规则均可能随产品与时间变化，请以发卡行最新条款为准。

    03 / METHOD

    省下的，
    是汇率里的细节。

    这里没有玄学。把一笔消费拆成“卡组织折算”和“银行购汇”两步，再把费用和返现放进去，结果就清楚了。

    01

    银行牌价，看卖出价

    你用人民币买外币还款，对应的是银行“现汇卖出价”，不是中间价，也不是现钞买入价。买入价和卖出价之间的差额，就是银行点差。

    02

    卡组织汇率，按加点模拟

    Visa、万事达、银联的入账汇率不对外提供稳定的静态接口。本页用“中间价 + 可调基点”模拟，默认万事达 25bp、Visa 35bp、银联 30bp。

    03

    费用和返现，一起算

    货币转换费按折算后金额加收；返现和积分折现按比例抵扣。你可以在“汇率与费用假设”里把每张卡改成自己的真实费率。

    预计入账 = 外币金额 × 卡组织折算率 × 银行购汇率 × (1 + 货转费) − 返现 / 积分折现

    本页是消费前的决策辅助，不是结算报价。银行牌价取自中国银行、中国工商银行、招商银行、交通银行官网快照；中间价来自 ExchangeRate-API；卡组织汇率与卡片费率为可调假设。实际入账金额、汇率时点、返现资格均以发卡行和卡组织为准。若收单方提供动态货币转换（DCC），通常应拒绝人民币定价，选择当地币种结算。
